# Verification Reports

Independent verification of merged changes: what was checked, how, and the
outcome. Distinct from `Tests/`, which holds test *procedures* to run, and from
`ScliTests/`, which holds automated test scripts. A report here records a
completed verification of a specific PR or change, static and/or on-device.
